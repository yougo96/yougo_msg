# Icônes des messageries

Les tracés `<id>.svg` viennent de [Simple Icons](https://simpleicons.org) (licence CC0 1.0), dans la couleur de chaque marque :
version 16.35.0, sauf LinkedIn (10.4.0, retiré des versions suivantes). Les logos restent des marques de leurs propriétaires.

`npm run icons` en tire les PNG de 256 px : `src/ui/sidebar/icons/<id>.png` (fond transparent, barre latérale) et
`assets/services/<id>.png` (sur une tuile sombre, notifications).
